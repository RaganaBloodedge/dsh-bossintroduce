# 投递配置（AutoIntroduce 初始化产物）

> 这里放**你个人的投递口径**，和引擎分开存放 —— skill 目录可以随便升级/分享，
> 这份文件跟人走。重跑初始化会被模板覆盖，手工改直接生效。
> 位置由 `scripts/paths.mjs` 解析：`AI_DATA_DIR` → `$AI_HOME/data`（默认 `~/.auto-introduce/data`）。
> 想知道当前实际读的是哪一份：`node scripts/flow.mjs where`。

## 硬过滤

| 项 | 值 | 判据 |
|---|---|---|
| 城市 | 例：北京 / 上海 / 杭州 | 岗位城市不在列表 → 跳过 |
| 意向标签 | 例：`C++`（对应岗位页上「C++（杭州）」那个按钮） | `flow.mjs pick --label "<意向标签>"` 用它切进意向筛选列表 |
| 薪资 | 左边界落在 **13K–20K**（含两端） | `13 <= salary_min <= 20` 才通过；右边界不参与判定 |
| 学历门槛 | 例：不高于硕士 | 岗位要求博士 → 跳过 |
| 经验年限 | `（未设）` | 不设表示本轮不卡，不是遗漏 |
| 毕业时间窗口 | `（未设）` | 设了就逐条核对（例：2026 届 → 岗位写「2027 年应届」跳过） |

## 触达与节奏

| 项 | 值 |
|---|---|
| 通道 | CDP 接管已登录浏览器（**可见**，不做无头） |
| 人工介入 | 文案过护栏后由执行器**直接发出**（`say`）；发出不可撤回，用户可随时叫停 |
| 循环次数 N | 默认 `10`（每轮找 N 个岗位、发 N 条文案） |

## 备注

- 判「薪资」只看**左边界**：岗位写「15–25K」按 15 判，写「20–40K」按 20 判，右边界写多少都不参与。
  左边界本身要有**上下界**（上表 13K–20K）：例「20–40K」按 20 判 → 通过；「25–40K」按 25 判 → **跳过**；
  「10–20K」按 10 判 → **跳过**（低于下界）。
- 岗位列表用**意向筛选**进入（点意向按钮），不要停在默认推荐流：意向列表在点击「立即沟通」后
  会自行刷新、把已沟通的岗位移出，推荐流不会。
